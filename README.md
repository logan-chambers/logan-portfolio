# Logan Chambers Portfolio

This version is built specifically for GitHub Pages.

## Run it locally

No Docker, Node.js, npm, or build step is required.

You can simply open `index.html` in a browser, or use any simple local web server.

## Publish with GitHub Pages

1. Create a GitHub repository for the portfolio.
2. Upload all files in this folder to the repository.
3. Commit and push the files to the `main` branch.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder.
7. Click **Save**.

GitHub Pages will publish `index.html` directly. There is no React build process and no Docker container involved.

## Website URL

For a repository named `portfolio`, the address will be:

`https://YOUR-USERNAME.github.io/portfolio/`

If the repository itself is named `YOUR-USERNAME.github.io`, the address will be:

`https://YOUR-USERNAME.github.io/`

## Updating the site

Edit `index.html`, commit the changes, and push them to GitHub. GitHub Pages will update the site automatically.
